# CipkoAI – Handwritten Digit Recognizer 🧠

CipkoAI is a simple handwritten digit recognizer powered by PyTorch and trained on the MNIST dataset.

Version: Alpha1.1(A1.1)

## 📝 NOTE
Please don't judge this AI model, IT'S NOT NEW CHATGPT! It's still in BETA. Improvements should come fast but for now it's pretty cool shit!

## 🚀 Features

- Convolutional Neural Network (CNN) for strong accuracy
- Supports custom image input (JPG/PNG/etc)
- Centered & contrast-enhanced preprocessing
- Configurable model settings via `config.json`

## 🤔 What you need?

- Just paint some handwritten digit(please make it big because then AI just don't recognize and just put 1 as prediction) and put the name of image + extension in the input

## 🛠 Requirements

- Python 3.8+
- Pip packages:
  pip install -r requirements.txt
